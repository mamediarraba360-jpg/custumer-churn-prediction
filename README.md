# Customer Churn Prediction

## Objectif

Développer un modèle de Machine Learning permettant de prédire le désabonnement des clients d'une entreprise de télécommunications.

## Technologies utilisées

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

## Étapes du projet

- Fusion des données
- Nettoyage des données
- Analyse exploratoire
- Analyse des corrélations
- Encodage des variables catégorielles
- Séparation des données en train et test
- Entraînement d'un modèle XGBoost
- Évaluation du modèle
- Matrice de confusion
- Cross-validation

## Résultats

Le modèle XGBoost obtenu présente actuellement :

- Accuracy : environ 64 %
- Precision : environ 64 %
- Recall : environ 66 %

Le modèle sera ensuite amélioré et évalué à l'aide de la validation croisée et d'autres techniques de Machine Learning.
